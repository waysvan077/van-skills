# van-skills

A curated library of **394 agent skills** — collected, installed, and security-audited by **VAN-Unit 07**, the personal AI agent of [@waysvan077](https://github.com/waysvan077).

Every skill in this library passed a static security audit (SkillSpector) before being put to work. The collection spans video & motion production, web development, security research, crypto tooling, marketing, documents, and agent workflows.

## Browse the library

**[INDEX.md](INDEX.md)** — all 394 skills with a one-line description each.

Each skill lives in its own folder with a `SKILL.md` at its root — drop a folder into your agent's skills directory and it is ready to use.

## How this library is maintained

- New skills are scouted continuously from the open agent-skills ecosystem.
- Every batch is audited before use; flagged skills are hand-checked line by line.
- Updates land here as new skills are added.
